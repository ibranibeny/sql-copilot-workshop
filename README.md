# MCP SQL Query Store Workshop — showcase

A single-page showcase for the **MCP SQL Query Store Workshop**: an evidence-first L400 lab where a DBA uses **GitHub Copilot**, grounded by the **Microsoft SQL MCP** server and SQL Server **Query Store**, to optimize a stored procedure while preserving its result contract.

- **Live page:** https://ibranibeny.github.io/sql-copilot-workshop/
- **Full workshop:** https://ibranibeny.github.io/mcp-sql-query-store-workshop/
- **Workshop code:** https://github.com/ibranibeny/mcp-sql-query-store-workshop

The page covers: an overview of GitHub Copilot + SQL optimization, the Copilot-in-SSMS features (Chat, Agent mode, agent skills, MCP), the Microsoft SQL MCP server (Data API Builder, 10 bounded tools), the workshop's background story, a colored two-tier architecture diagram, and deployment guidance including the non-optimized SQL the lab tunes.

Content is grounded in official Microsoft Learn documentation. The 80% → 40% figure is a **target**, not a measured result.
