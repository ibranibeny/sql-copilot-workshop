# GitHub Copilot in SSMS Workshop — L300

An **L300 narrative workshop** where Maya, a database platform engineer, uses **GitHub Copilot in SQL Server Management Studio**, grounded by actual execution plans and SQL Server **Query Store**, to explore an unfamiliar schema and optimize a stored procedure while preserving its result contract.

- **Live page:** https://ibranibeny.github.io/sql-copilot-workshop/
- **Full workshop:** https://ibranibeny.github.io/mcp-sql-query-store-workshop/
- **Workshop code:** https://github.com/ibranibeny/mcp-sql-query-store-workshop

The six-step story moves from a finance incident through Copilot-assisted schema exploration, hypothesis formation, isolated deployment, architecture review, and an evidence-backed tuning decision. Detailed deployment commands and faithful SQL excerpts remain available in collapsible lab panels.

Content is grounded in official Microsoft Learn documentation. The 80% → 40% figure is a **target**, not a measured result.
