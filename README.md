# GitHub Copilot in SSMS Workshop

A six-step guided workshop where a DBA uses **GitHub Copilot in SQL Server Management Studio**, grounded by actual execution plans and SQL Server **Query Store**, to explore an unfamiliar schema and optimize a stored procedure while preserving its result contract.

- **Live page:** https://ibranibeny.github.io/sql-copilot-workshop/
- **Full workshop:** https://ibranibeny.github.io/mcp-sql-query-store-workshop/
- **Workshop code:** https://github.com/ibranibeny/mcp-sql-query-store-workshop

The page covers: an overview of GitHub Copilot, Copilot-in-SSMS features (Chat, completions, Agent mode, agent skills, and optional MCP servers), the AI schema-exploration and SQL-optimization use case, a complete deployment guide, a colored two-tier architecture diagram, and the attached SSMS demonstration screenshot.

Content is grounded in official Microsoft Learn documentation. The 80% → 40% figure is a **target**, not a measured result.
