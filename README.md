# GitHub Copilot in SSMS Workshop — L300

An **L300 narrative workshop** where the database platform team at **Contoso AI** uses **GitHub Copilot in SQL Server Management Studio**, grounded by actual execution plans and SQL Server **Query Store**, to explore an unfamiliar schema and optimize a stored procedure while preserving its result contract.

- **Live page:** https://ibranibeny.github.io/sql-copilot-workshop/
- **Full workshop:** https://ibranibeny.github.io/mcp-sql-query-store-workshop/
- **Workshop code:** https://github.com/ibranibeny/mcp-sql-query-store-workshop

The six-step story moves from a finance incident through Copilot-assisted schema exploration, hypothesis formation, isolated deployment, architecture review, and an evidence-backed tuning decision. Detailed deployment commands and faithful SQL excerpts remain available in collapsible lab panels.

The overview includes an original Draw.io context-flow diagram based on Microsoft Learn guidance and an architecture pattern discovered through WebIQ. The Azure lab diagram is also authored in Draw.io and uses unmodified, labeled icons from the official Azure Architecture Icons collection. Both diagrams are published as SVG with embedded Draw.io XML, and their native `.drawio` sources remain available under `assets/`.

Content is grounded in official Microsoft Learn documentation. The 80% → 40% figure is a **target**, not a measured result.
